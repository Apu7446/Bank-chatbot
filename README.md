# SBAC Bank PLC — Website Portal & AI Chatbot 🏦🤖

A modern, responsive web portal for **South Bangla Agriculture and Commerce (SBAC) Bank PLC** featuring an intelligent bilingual AI chatbot assistant for real-time customer banking support.

---

## 🌟 Key Features

- **🤖 Smart Bilingual AI Chatbot**: Supports queries in both Bengali (বাংলা) and English with instant natural language understanding.
- **💳 Accounts & Cards Information**: Instant guidance on Savings accounts, Fixed Deposits (FDR), DPS schemes, Islamic Banking, and Credit/Debit cards.
- **📱 BanglaPay Digital Banking**: Direct information and access to SBAC's mobile app (BanglaPay) features and downloads.
- **📍 Branch & ATM Locator**: Quick lookup for SBAC Bank branches, sub-branches, ATM booths, and headquarters.
- **📞 Direct Hotline & Customer Care**: Instant dial access to 16327 hotline and support contacts.
- **🎨 Modern & Responsive Design**: Crafted with pure CSS, modern glassmorphism, smooth animations, and SBAC corporate branding.
- **⚡ Lightweight & Fast**: Built without heavy framework dependencies; pure HTML5, CSS3, and ES6 JavaScript.

## 🛠️ Technology Stack

- **Frontend**: HTML5, Vanilla CSS3 (Custom Design System)
- **Scripting**: Vanilla JavaScript (ES6 Modules & Event-driven architecture)
- **Typography**: Google Fonts (*Outfit*, *Plus Jakarta Sans*, *Hind Siliguri*)
- **Icons & Markdown**: FontAwesome 6.5, Marked.js (for rich response formatting)

## 🚀 How to Run Locally

1. Clone or download the repository to your local machine:
   ```bash
   git clone <YOUR_REPOSITORY_URL>
   cd "SBAC WEBSITE CHAT_BOT"
   ```

2. Open the project:
   - Simply double-click `index.html` to open it in any modern browser (Chrome, Edge, Firefox).
   - Or use VS Code's **Live Server** extension for the best development experience.
